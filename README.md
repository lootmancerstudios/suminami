# Suminami

A polished Hyprland desktop rice with rich theming, custom modals, and cohesive design.

## Overview

Suminami is a complete desktop experience built around the Kanagawa color palette (with additional theme options). Every component is designed to work together seamlessly.

## Components

| Component | Description |
|-----------|-------------|
| Hyprland | Window manager configuration |
| Waybar | Status bar with rich tooltips |
| Rofi | Application launcher and custom menus |
| Notifications | Styled notification system |
| Lock Screen | Themed lock screen |
| And more... | Terminal, GTK theming, etc. |

## Structure

```
suminami/
├── config/           # Application configs (symlinked to ~/.config/)
│   ├── hypr/         # Hyprland, hyprlock, hypridle configs
│   ├── waybar/       # Status bar and scripts
│   ├── dunst/        # Notification styling
│   └── btop/         # System monitor config
├── scripts/          # Hub menus, theme generation, utilities
├── themes/           # GTK themes
├── wallpapers/       # Matching wallpapers
└── install.sh        # Installer
```

## Architecture

Suminami uses **symlinks** to connect your `~/.config/` to the repo. This means updates are automatic with `git pull`.

| Directory | Symlinked | Notes |
|-----------|-----------|-------|
| `~/.config/hypr` | Yes | Hyprland, hyprlock, hypridle |
| `~/.config/waybar` | Yes | Status bar and scripts |
| `~/.config/dunst` | Yes | Notifications |
| `~/.config/btop` | Yes | System monitor |
| `~/.config/rofi` | No | Auto-generated by theme system |

**User-specific config:** Your `monitors.conf` is gitignored and never overwritten by updates. Edit it freely for your display setup.

## Updating

Use the **Update** option in the Hub menu (Super+A), or manually:

```bash
cd ~/.config/suminami && git pull
```

The Hub menu update also regenerates themes and reloads all components automatically.

## Installation

```bash
curl -s https://raw.githubusercontent.com/lootmancerstudios/suminami/main/install.sh | bash
```

> Works in bash, zsh, and fish.

**Prefer to review before running?** The installer uses `sudo` to install packages, so it's reasonable to inspect it first:

```bash
curl -fsSLO https://raw.githubusercontent.com/lootmancerstudios/suminami/main/install.sh
less install.sh   # review
bash install.sh
```

## Timezone (for travelers)

Linux keeps a **fixed** timezone — it won't follow you when you travel, so your clock can show the wrong time in a new region. Two options:

- **Automatic:** the installer offers an opt-in prompt (default **off**) to enable automatic timezone updates via `tzupdate` (a systemd timer that detects your location from your IP). Enable it if you move between timezones often.
- **Manual:** set it yourself anytime:

  ```bash
  sudo timedatectl set-timezone America/Toronto   # see: timedatectl list-timezones
  ```

The Waybar clock follows the system timezone automatically — no config change needed.

## Theme System

Themes are defined centrally in `themes/` and applied across all components. Changing your theme updates everything at once.
